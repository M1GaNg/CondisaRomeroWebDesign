# Website Condisa Romero

Sitio web desarrollado con **React** y **Vite** para la empresa Condisa Romero Servicios Generales & Construcciones S.A.C.

## 🚀 Tecnologías

- [React](https://react.dev/)
- [Vite](https://vitejs.dev/)
- [ESLint](https://eslint.org/)
- [CSS](https://developer.mozilla.org/en-US/docs/Web/CSS)

## 📁 Estructura del proyecto

```
website-condisa-romero/
│
├── public/                # Archivos estáticos
├── src/                   # Código fuente principal
│   ├── assets/            # Imágenes y recursos
│   ├── components/        # Componentes reutilizables
│   ├── hooks/             # Custom hooks
│   ├── pages/             # Páginas principales (Home, Projects, etc.)
│   └── App.jsx            # Componente raíz
├── .gitignore
├── index.html
├── package.json
├── README.md
└── eslint.config.js
```

## 🛠️ Instalación

1. **Clona el repositorio**
   ```bash
   git clone https://github.com/tu-usuario/website-condisa-romero.git
   cd website-condisa-romero
   ```

2. **Instala las dependencias**
   ```bash
   npm install
   ```

3. **Inicia el servidor de desarrollo**
   ```bash
   npm run dev
   ```

4. Accede a [http://localhost:5173](http://localhost:5173) en tu navegador.

## 📄 Páginas principales

- **Home:** Página principal con información de la empresa y servicios.
- **Projects:** Portafolio de proyectos realizados, con carrusel de imágenes.
- **Service:** Detalle de servicios ofrecidos.
- **Contacto:** Información de contacto y ubicaciones.

## 🧹 Linting

Para analizar el código y corregir errores de estilo:
```bash
npm run lint
```

## 📦 Build

Para generar la versión de producción:
```bash
npm run build
```
